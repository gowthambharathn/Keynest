# KeyNest 🔑

**KeyNest** is a lightweight Android library that makes local data storage simple, fast, and developer-friendly.

## Features

* 🚀 Lightweight and fast
* 📦 Easy integration
* 🧩 Clean and intuitive API
* 💾 Efficient local data storage
* 🛠️ Built for Android developers


## Requirements

* Android API 24+
* Kotlin
* Jetpack Compose
