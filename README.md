# KeyNest 🔑

**KeyNest** is a lightweight Android library that makes local data storage simple, fast, and developer-friendly.

## Features

* 🚀 Lightweight and fast
* 📦 Easy integration
* 🧩 Clean and intuitive API
* 💾 Efficient local data storage
* 🛠️ Built for Android developers

## Installation

### Step 1: Add JitPack

```kotlin
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven("https://jitpack.io")
    }
}
```

### Step 2: Add the dependency

```kotlin
dependencies {
    implementation("com.github.gowthambharathn:KeyNest:TAG")
}
```

Replace `TAG` with the latest release version.
